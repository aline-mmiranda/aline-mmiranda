## 🚀 Projetos em destaque

### 🎨 [Css Gerados com IA](https://github.com/aline-mmiranda/css-gerador-ia)
Aplicação web que gera código CSS a partir de descrições em linguagem natural via API de IA generativa. O usuário descreve um elemento visual e a aplicação retorna o CSS gerado e renderiza o preview em tempo real.
`JavaScript` · `Groq AI API` · `Fetch` · `async/await` · `DOM dinâmico`

### 🎲 [sortea.](https://github.com/aline-mmiranda/sortea)
Gerador de números aleatórios com foco em experiência do usuário, validação de entradas e boas práticas de código. Implementa state machine para gerenciamento de estados da UI e animação Lottie durante o sorteio.
`JavaScript` · `State Machine` · `Lottie` · `Glassmorphism` · `Responsivo`
